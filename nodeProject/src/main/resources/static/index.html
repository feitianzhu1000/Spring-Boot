MARKDOWN 101

把想法写成
清晰的 Markdown

Markdown 是一种轻量级标记语言。用少量符号就能写出结构清楚的日志、笔记和说明文档， 文件本身保持纯文本，也很容易被其他工具阅读。

01 / 层级

标题与段落

使用井号表示标题级别，井号越少，标题级别越高。段落之间空一行。

Markdown 
# 一级标题
## 二级标题
### 三级标题

这是一个普通段落。
# 一级标题
## 二级标题
### 三级标题

这是一个普通段落。

02 / 重点

强调与引用

用星号或下划线强调内容，用反引号标记行内代码，用大于号写引用。

Markdown 
**加粗文字**
*斜体文字*
`行内代码`

> 这是一段引用。
**加粗文字**
*斜体文字*
`行内代码`

> 这是一段引用。

05 / 技术

代码块

使用三个反引号包住多行代码，并在开头标注语言名称，可以获得语法高亮。

Markdown 
```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
```
```java
public class Hello {
    public static void main(String[] args) {
    System.out.println("Hello");
    }
}
```
效果 
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}

表格

| 页面 | 已完成 |
| 接口 | 待开发 |
